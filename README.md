# HOLLOW HOUR

A story-driven browser RPG with bullet-dodge boss fights, multiple routes and 7 endings.

**Play:** download `index.html` and open it in any modern browser. It's one offline file and works on desktop and on phones in landscape.

- Director: Delon Nicholas
- Design, code and writing: Hoppy

![Title](screenshots/shot_title_v20.png)

## Build from source
`python3 build.py` assembles `src/` into `index.html` and `index.min.html`.

See `RELEASE_NOTES.md` for what's in v2.0.
