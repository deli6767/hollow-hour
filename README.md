# HOLLOW HOUR

A story-driven browser RPG with bullet-dodge boss fights, multiple routes and 8 endings.

**Play online:** https://deli6767.github.io/hollow-hour/

**Play offline:** download `index.html` and open it in any modern browser. It's one offline file and works on desktop and on phones in landscape.

- Director: Delon Nicholas
- Design, code and writing: Hoppy
- Music, sound effects and sprites: Greg
- Playtesting: Smith

## Build from source
`python3 build.py` assembles `src/` into `index.html` and `index.min.html`.

See `RELEASE_NOTES.md` for what's in v2.0 and each patch (latest: v2.0.3).
